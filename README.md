# Neon Outpost

A tiny, dependency-free browser shooter with tower-defense pressure. Protect the reactor, survive escalating waves, earn XP from kills, and choose an upgrade whenever you level up.

## Play

Open `index.html` in a browser, or serve the folder with any static web server.

- `WASD` to move
- Mouse to aim
- Click to fire
- `Space` to dash
- Press `T`, then click the arena to place up to four auto-firing sentries
- On mobile, use the touch joystick and `FIRE` button

## Threats

Drone swarms are fast, brutes are durable, shooters fire back, and a Warden boss arrives every fifth wave. Boss defeats repair the reactor.
